Between large multi-year museum builds, a lot of my favourite technical work happens in smaller R&D sprints, public art commissions, and weekend repos.

## The Pipes at Cato Square (2019)

At REELIZE.STUDIO, working with Ramus Lighting, I built custom Unity creator tools for *The Pipes* at Cato Square in Prahran: 28 eleven-metre vertical LED poles arranged across an urban park. The Unity tooling let lighting designers preview volumetric animations in 3D space and export clean pixel-mapped playback directly to the site controllers.

## AP Lab (2021 - present)

At Art Processors I wrote the charter for AP Lab and have run the internal prototyping lab since 2021. The lab exists to test technologies before we ever pitch them to a museum client:

- **Spatial and display prototypes:** holographic display hardware evaluations, geo-located outdoor AR experiments, and VR museum gallery simulators for testing sightlines before fabrication.
- **Voice and generative AI studies:** a 2023 voice-cloning and ethics evaluation conducted with Gil Fewster, followed by an internal 2024 AI ethics proposal establishing clear consent and disclosure boundaries for cultural institutions.

## Independent code and hardware

Outside client work, I keep building small tools and playful experiments:

- **[little-quest](https://scroix.github.io/little-quest/) (2026):** a small interactive game built in Rust and GPUI while exploring native GPU-accelerated UI outside the browser.
- **[nodel-skills](https://github.com/scroix/nodel-skills) (2026):** Python tooling and agent skills for inspecting, debugging, and scripting live Nodel hosts via REST.
- **[matrix-midi-xy](https://github.com/scroix/matrix-midi-xy) (2020):** a Purr Data patch turning a woven eTextile sensor matrix into an expressive XY MIDI controller.
- **Containerised GAN ports (2020):** open Docker setups for [MUNIT-runway](https://github.com/scroix/MUNIT-runway) and [TecoGAN](https://github.com/scroix/TecoGAN) created while testing generative video workflows.
